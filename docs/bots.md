# 봇 — 혼자서 플레이 · 학급 시뮬레이션

작성: 2026-09-25. 봇은 사람이 모자랄 때 자리를 채우거나, 혼자 연습하거나, 수업 전에 선생님이 게임 흐름을 미리 돌려 보기 위한 가짜 참가자다.

## 1. 쓰는 곳

| 어디서 | 누가 | 하는 일 |
|---|---|---|
| 처음 화면 → **🤖 혼자서 플레이** | 누구나 | 규칙(표준 대전·협력), 내 역할(추측자·스파이마스터·관전만), 내 팀, 인원(표준 4~8, 협력 2~6), 난이도(상대 팀 봇 실력), 우리 팀 봇 실력, 봇 속도를 고르면 나 + 봇으로 방을 만들고 바로 시작한다. 다른 사람은 들어올 수 없다. 끝나면 ‘다시 하기’(같은 구성으로 새 판) · ‘설정 바꾸기’(대기실) |
| 독립 게임방 대기실 | 방장 | 사람이 모자라면 ‘봇 넣기’(한 방에 최대 8명). 봇의 팀·역할을 바꾸거나 뺄 수 있다. 게임 중 봇 자리를 늦게 온 사람이 이어받을 수 있다(자리 재지정) |
| 학급 대시보드 → **🤖 시뮬레이션 방 만들기** | 선생님 | 봇으로 모든 자리를 채운 방을 만든다(학생 없이 시범·리허설). 학생 방장이 없는 방에서는 선생님이 방장 역할(시작·팀 나누기·중단·대기실로)을 한다 |
| 학급 대시보드 방 카드 / 학생의 ‘내 방 관리’ / 학급 방 대기실 | 그 방의 방장 학생, 선생님 | 대기 중인 방의 빈자리를 봇으로 채우거나 뺀다. 봇은 클래스 좌석을 쓰므로 방 정원에는 들어가고, 학생 수(정원 40/60명)·미배정 수에는 들어가지 않는다 |

**정답 보며 관전:** 참가자가 모두 봇인 게임이면 방장(학급에서는 선생님)이 ‘정답 보며 관전’을 켤 수 있다. 관전 화면에 정답과 ‘봇 스파이마스터가 노린 단어’가 보인다. 사람 참가자가 한 명이라도 있으면 켜도 서버가 정답을 보내지 않는다.

## 2. 봇이 지키는 약속

- **사람과 같은 명령 경로.** 봇의 힌트·추측·턴 종료·판정은 사람이 WebSocket 으로 보내는 것과 같은 `applyCommand`(차례·역할·revision·게임 규칙 검사)를 거친다. 규칙 엔진이 봇을 따로 봐주지 않는다.
- **자기 자리의 화면만 본다.** 봇은 그 자리로 projection 한 `GameView` 하나만 입력으로 받는다. 봇 추측자의 화면에는 미공개 정답(key)이 없다. 단위 테스트가 ‘서버의 정답 배치를 뒤섞어도 봇 추측자의 선택이 같다’를 확인한다.
- **사람 추측자가 있는 팀에서는 사람이 정한다.** 그 팀의 봇 추측자는 카드를 고르지 않고, 힌트를 어떻게 읽었는지만 토론 채팅에 한 번 남긴다(예: `‘바다’ 2 → 고래, 파도 쪽이 떠올라요.`).
- **사람이 연결되어 있을 때만 움직인다.** 방에 연결된 사람(참가자·관전 교사)이 없으면 봇은 쉬고, 누가 다시 들어오면 이어서 둔다. 봇 차례는 Durable Object alarm 으로 실행되므로 서버가 잠들었다 깨어도 이어진다.
- **봇은 신고하지 않는다.** 사람이 이의 신고를 하면 봇 스파이마스터는 ‘판에 보이는 단어와 같거나 글자로 겹치는가’로 판정하고, 사전 문의에도 같은 기준으로 답한다.
- **표시.** 봇은 이름이 ‘봇 ○○’이고 🤖 표시와 실력이 붙는다. 사람으로 오해하지 않게 한다.
- **정리.** 봇은 방 상태의 일부라 방이 닫히거나 만료되면 함께 사라진다. 학급 봇은 방을 닫거나 수업을 끝내면 클래스에서도 지워진다.

## 3. 봇의 생각 (연상 사전)

봇은 외부 AI 를 부르지 않는다. 이 프로젝트가 만든 연상 사전 `content/bots/ko-associations.json` 만 쓴다 (서버 전용, 클라이언트 번들에 없음).

- 기본 단어 팩(자체 제작 400단어) 각 단어의 연상 10~12개 (앞쪽일수록 강함) — 서로 다른 말 약 2,000개
- 분류·주제 묶음 95개 (동물·과일·나라·직업·바다·하늘·겨울·크리스마스…)
- 가까움 점수 0~1: 직접 연상(0.62~1.0) · 같은 분류(0.84) · 드문 연상을 함께 가짐(최대 0.45) · 글자 포함(0.8)

**스파이마스터 봇**은 자기 팀 단어들의 연상 후보를 모아, 판에 보이는 단어와 겹치지 않고(글자 포함까지 엄격하게), 팀 색·게임 용어가 아닌 한글 단어 중에서 ‘우리 단어는 가깝고 상대·시민·암살자 단어는 충분히 먼’ 힌트를 고른다. 노린 카드는 서버에만 적어 두고, 게임이 끝나야(또는 모두 봇인 게임을 정답 보기로 관전할 때만) ‘노린 단어’로 보여 준다.

**추측자 봇**은 힌트와 각 카드의 가까움에 실력별 흔들림을 더해 순서를 정하고, 상대 팀 힌트와 가까운 카드는 피한다. 첫 추측은 반드시 하고(p.4), 그 뒤에는 점수가 기준보다 낮으면 멈춘다. ‘보통’·‘어려움’은 지난 힌트에서 못 찾은 단어로 +1 추측(p.5)도 쓴다. 사전에 없는 힌트는 ‘모르는 말’이라고 채팅에 남기고 짐작으로 한 장만 고른다.

| 실력 | 한 힌트 최대 | 노리는 연결 | 여유(상대·시민 / 암살자) | 추측 흔들림 | +1 추측 |
|---|---|---|---|---|---|
| 쉬움 | 2장 (반은 1장만) | 0.72 이상 | 0.25 / 0.35 | 큼 | 안 함 |
| 보통 | 3장 | 0.66 이상 | 0.15 / 0.28 | 보통 | 확실할 때만 |
| 어려움 | 4장 | 0.45 이상 (약한 연결 포함) | 0.10 / 0.20 | 작음 | 함 |

봇 속도(운영 설정): 천천히 · 보통(힌트 4.5~8초, 첫 추측 3~5.5초) · 빠르게(1~2초).

## 5. 한계 (정직하게)

- **봇은 사전에 있는 연결만 안다.** 처음 1~3번째 힌트는 2~4장을 묶지만, 남은 단어끼리 사전 연결이 없으면 1장짜리 힌트를 준다. 그래서 평균 숫자가 사람보다 낮다(위 표). 어려움도 크게 다르지 않다 — 더 과감하게 묶을 연결 자체가 사전에 없기 때문이다. 사전을 늘리면 좋아진다.
- **사람이 준 힌트가 사전에 없으면 봇 추측자는 잘 모른다.** 별칭(‘빨간색’→‘빨강’)과 흔한 접미사(‘동물들’)는 맞추지만, 사전에 없는 말은 짐작한다. 채팅의 ‘모르는 말’ 안내로 알 수 있다.
- **봇 스파이마스터는 연상 사전이 모든 단어를 아는 팩에서만 쓸 수 있다.** 지금은 자체 제작 팩 400/400. 직접 입력한 단어 팩이나(추후) 한국어 정식판 팩에서는 시작할 때 막고 안내한다(봇 추측자만이면 된다). `npm run content:verify` 가 팩별 사전 적용 범위를 보고한다.
- 봇 수: 독립 방 최대 8명, 학급은 방 정원까지. 봇의 해석 채팅은 추측자 봇만 남긴다(스파이마스터는 게임 중 채팅 금지 규칙을 봇도 지킨다).
- 봇끼리 대전 측정은 이 앱의 봇 사이의 결과다. 사람과 둘 때의 체감 난이도는 측정하지 않았다.
- **봇도 Cloudflare 사용량을 쓴다.** 봇의 행동 하나가 Durable Object 요청 1건(alarm)이고, 학급 방에서는 진행 요약을 클래스에 알리는 요청이 더해진다. 봇만 있는 4인 게임 한 판은 대략 50~100건이다. 무료 플랜의 하루 한도(10만 건)는 README ‘사용량과 비용’ 참조.
