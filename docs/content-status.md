# 콘텐츠 현황과 데이터 미확보 목록

**요약: 엔진·통신 구현은 끝났고, 원본 콘텐츠 검증은 끝나지 않았다.**
정식 모드(한국어 정식판 단어 + 원본 키 카드)는 자료가 없어서 잠겨 있다. 지금 배포된 앱은 아래의 비공식 팩으로 플레이한다.

## 설치된 팩

| packId | 종류 | 상태 | 내용 | 정체 배치 |
|---|---|---|---|---|
| `ko-official-classic` | 정식 | `missing` (자료 미확보) | 비어 있음. 정식 모드 시작 불가, 대기실에서 선택 불가로 표시 | 원본 키 40장 (미확보) |
| `ko-original-v1` | 자체 제작 비공식 | `unofficial` | 이 프로젝트가 고른 일반 명사 400개를 임의로 앞뒤 짝지은 200장. **원작 한국어판 단어 목록이 아니다** | 무작위 9/8/7/1 (원본 키 아님) |
| `custom` (방마다) | 직접 입력 비공식 | 방장이 25개 이상 입력하면 사용 가능 | 한 면 카드 | 무작위 9/8/7/1 (원본 키 아님) |
| 테스트 픽스처 | 합성 | `testOnly` | `tests/fixtures/test-pack.ts`. 단위 테스트에서만 쓰며 Worker 번들에 들어가지 않음 | 합성 키 (실제 배치 아님) |

규칙 수치(25칸, 9/8/7/1, 추측 수, 승패)는 어느 팩이든 기본판과 같다. 팩은 단어만 바꾼다.

## 데이터 미확보 목록

| # | 항목 | 현재 | 필요한 것 |
|---|---|---|---|
| 1 | 한국어 정식판 단어 카드 200장 · 400단어 | 없음 | 실물 카드의 면별 단어를 옮겨 적은 목록 |
| 2 | 카드 200장의 앞뒤 짝 | 없음 | 카드마다 A면·B면이 무엇인지 (추정 금지) |
| 3 | 원본 키 카드 40장의 배치 | 없음 | 카드마다 25칸의 정체(R/B/N/A)와 선공 불빛 색. 기준 방향을 하나로 정해 기록 |
| 4 | 한국어 정식판 발행처·판본·인쇄 연도 | 미확인 | 상자·규칙서의 판권 면 |
| 5 | 한국어 규칙서와 2015 영문 룰북의 차이 | 미확인 | 한국어 규칙서 대조. 차이가 있으면 별도 규칙 프로필로 분리 |
| 6 | 영문판 데이터 | 사용하지 않음 | 지시서의 공개 저장소(koosvary, Gullesnuffs) 목록은 참고 후보일 뿐 정식 데이터·짝·키의 증거가 아니다. 이 프로젝트는 그 목록을 가져오지 않았다 |

금지 사항(지키고 있음): 무작위 배치를 원본 키라고 부르지 않는다. 영문 단어를 번역해 정식 한국어판이라고 부르지 않는다. 앞뒤 짝을 추정하지 않는다. 빠진 단어를 지어내 정식판에 넣지 않는다. 출처 없는 데이터를 검증 완료로 표시하지 않는다.

## 정식 자료를 넣는 순서

1. 실물 카드를 보며 CSV 두 개를 만든다 (UTF-8, BOM 없음). 형식 예시: `content/examples/cards.example.csv`, `content/examples/keys.example.csv`
   - 카드: `id,faceA,faceB,sourceReference`
   - 키: `id,startingTeam,grid,sourceReference` — `grid` 는 행 우선 25글자 `R`(빨강) `B`(파랑) `N`(시민) `A`(암살자)
2. 가져오기: `npm run content:import -- --pack ko-official-classic --cards 카드.csv --keys 키.csv --source "2026-10-01 실물 대조 (홍길동)"`
   - 가져오기만으로는 `unverified` 가 된다. 검증 완료로 표시하지 않는다.
3. 검사: `npm run content:verify` — 수량(200/400/40), 고유 id, NFC, 제어 문자, 키마다 9/8/7/1 과 선공 일치, 중복 의심 단어(삭제하지 않고 경고)를 확인한다.
4. 사람이 실물과 한 번 더 대조한 뒤 `content/packs/ko-official-classic/manifest.json` 의 `validationStatus` 를 `verified` 로 바꾼다.
5. `npm run content:verify -- --write` 로 `docs/content-verify-report.md` 를 갱신하고 배포한다.
6. **저작권 주의:** 정식판 단어 목록과 키 배치는 출판사 자료다. 지금 GitHub 저장소는 공개(public) 상태이므로, 정식 자료를 커밋하기 전에 저장소를 비공개로 바꾸는 것을 권한다. 키 카드는 서버 번들에만 들어가고 프런트엔드 공개 경로로는 복사되지 않는다(`release:check` 가 확인).

JSON Schema: `content/schema/manifest.schema.json`, `word-cards.schema.json`, `key-cards.schema.json`.
